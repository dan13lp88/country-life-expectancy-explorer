# Compare Life Expectancy by Country

An interactive Streamlit web application for comparing life expectancy trends between two countries over a selected year range.

## Features

- Select any two countries
- Choose a year range
- Review a year-by-year comparison table
- See the life-expectancy difference
- Identify which country has the higher life expectancy in the latest selected year
- Explore bar-chart and trend-chart visualizations

## Technology

- Python
- Streamlit
- Pandas
- Altair
- Public life-expectancy data from Our World in Data

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
